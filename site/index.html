    Yours, on your Mac.

    CAD Studio runs the agent you already use, in a folder you choose. No accounts, no servers, nothing uploaded by the app.

    Show it what you mean.

    Paste a screenshot with ⌘V, or drop in a sketch, a photo, a PDF drawing or the STEP of the part it has to fit. The agent measures what it can instead of guessing.

    Line up the next idea.

    Keep typing while it works. Messages wait in a queue and go out one by one as each version finishes. If something fails, the queue pauses for you.

    Everything in the box.

    One app, from the first sentence to the file on your print bed.

    Design

    • Chat that writes and fixes the parametric model for you
    • Named parameters as sliders, rebuilt locally in seconds
    • Reference images, sketches, PDFs and STEP or STL files
    • Message queue that sends the next request when a version is done
    • Build checks on every run: valid solids, warnings and errors in the chat

    View

    • Live 3D view with orbit, zoom, pan, grid and wireframe
    • Multi-color 3MF parts, shown in their real colors
    • Assembled, exploded and print plate views
    • Show, hide or keep parts together
    • Point-to-point measurements and section planes on X, Y and Z

    Simulate

    • Mechanisms animated by a physics simulation
    • Masses, springs, friction and the force of your hand
    • Collision checks on the real solids while it moves
    • Live readouts of speeds, angles and forces as it plays

    Document

    • ISO first-angle technical drawings with every model
    • Assembly sheet with balloons and a parts list
    • One sheet per part, with its own dimensions
    • All sheets in one multi-page PDF

    Print

    • Design rules for FDM, multi-material, resin and SLS
    • Print plate with every part oriented and laid out
    • The print plate opened straight in your slicer
    • STEP, 3MF, STL, the PDF drawing and the source script in one ZIP

    Work your way

    • Every generation saved as a version, chat and context included
    • Compare any two versions in 3D
    • Panels you can drag anywhere, layout saved per project
    • Each project is a plain folder you can open, copy or back up
    • English, Italian, German and French

    Bring your own agent.

    CAD Studio has no AI of its own and no account to make. It drives the coding agent already signed in on your Mac, with your plan, and you can switch agents in Settings at any time.

    1. You describe it.

      In words, with pictures or with the file it has to fit. In millimeters or inches.

    2. The agent writes the code.

      A parametric script with every dimension as a named parameter, plus the drawing and the simulation.

    3. It runs and checks.

      The model is built right on your Mac. The agent looks at the drawings it produced and fixes what is wrong.

    4. You get files.

      Ready for your slicer, your CAD app and your workshop, in a folder you own. Nothing leaves your Mac through the app.

    Get CAD Studio.

    Free and open source. For macOS 15 or later.

    Download for macOS View the source

    1. Sign in to your agent.

      Install Claude Code and run claude once, or install Codex and run codex login. CAD Studio uses your plan.

    2. Open CAD Studio.

      Drag it into Applications. It isn't notarized yet, so allow it in Privacy & Security, or run:

      xattr -dr com.apple.quarantine "/Applications/CAD Studio.app"

    3. Describe a part.

      Pick your printer and units, and say what you need. Everything else is set up for you on first launch.
